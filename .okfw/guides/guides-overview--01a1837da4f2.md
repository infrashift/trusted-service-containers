# Guides overview

This bundle holds the rules for the wiki: how to write, which words to use, and how to track issues and plans.

Do not put facts about the system here. Put them in `architecture/`, `supply-chain/` or `operations/`.

## Find concepts

* List this bundle: read `.okfw/guides/index.md`.
* Search the guides: `okfw search "<words>" --type guide`.

## Add a concept

1. Search the wiki first. Update a concept that exists, if possible.
2. Run `okfw create "<Title>" --type guide --path guides -d "<one sentence>" --tags guide`.
3. Add a link to the new concept in the list below.
4. Obey the [wiki conventions](/guides/wiki-conventions--01a1837da62e.md) and [Simplified Technical English](/guides/simplified-technical-english--01a1837da5eb.md).
