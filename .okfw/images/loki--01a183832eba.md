# loki

loki is the Grafana Loki log store, with the `logcli` query client. We build it from source onto `ubi9-micro`.

## Track

Build track. We compile `loki` and `logcli` from the pinned `sources.loki` commit with `Containerfiles/loki.Containerfile`. The source track is the 3.7 minor line. See [Build track](/architecture/build-track--01a18382f2d2.md).

No usable UBI-based Loki exists. The Red Hat image needs an entitled, authenticated pull, and it follows the OpenShift Logging release train. The vendor image is distroless/static, based on Debian.

## Trust class

`internal`. We verify our `ubi9-micro` base against the release key of `infrashift/trusted-base-images`. See [Upstream trust classes](/architecture/upstream-trust-classes--01a18382f3fb.md).

The binary cross-check compares our binary with the binary in `docker.io/grafana/loki`, trust class `none`, tier `best-effort`. The upstream builds without `-trimpath`. It stamps a clock build date and a build user. Thus a byte mismatch is expected and proves nothing, even on the same Go patch. See [ADR-004: Dual provenance is an observation, not a gate](/decisions/adr-004-dual-provenance-is-an-observation-not-a-gate--01a18382f4a6.md).

## Enforcement

## Variants and platforms

One variant, `runtime`. Architectures: `amd64`, `arm64`. The upstream index also has arm/v7. We do not build it.

## Runtime

* Port: 3100.
* Volume: /loki. It holds the chunks, the TSDB index, the WAL and the working directory of the compactor. Without a persistent mount, each restart loses all stored logs. Nothing shows the loss.
* Command: `loki` with the upstream Docker configuration, with file storage under /loki. Like the vendor image, the image can run alone. A real deployment mounts its own configuration.
* User: 1001.

## Notes

* The tags and ldflags come from the upstream Makefile: `-s -w`, `-tags netgo`, `CGO_ENABLED=0`. `-trimpath` is ours.
* The version is the ref without its leading `v`. The revision is the pinned `shortCommit`. The vendor stamps the dynamic abbreviation of git, which has 8 characters. The branch is `HEAD`. The build date is the source commit date, not the clock.
* The Containerfile checks the version output. An ldflags path that no longer matches still links, and the binary then reports an empty version.
* `GOTOOLCHAIN=local`. See [Toolchain pins](/architecture/toolchain-pins--01a18382f31f.md).
* The image contains `logcli` on purpose. It is the query client of the operator. Consumers run it from this signed image, not from an unpinned download.
* Licence: AGPL-3.0-only, with Apache-2.0 subfolders in pkg/. We run it unmodified and internally.
* Consumer: `infrashift/ansible-collection-infrashift-hashistack`, terraform/live/loki.
