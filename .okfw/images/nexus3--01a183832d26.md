# nexus3

nexus3 is the Sonatype Nexus Repository 3 artifact manager. We mirror the UBI-based image of the vendor from Docker Hub.

## Track

Mirror track, from `docker.io/sonatype/nexus3`. See [Mirror track](/architecture/mirror-track--01a18382f29c.md).

## Trust class

`none`. The image is public on Docker Hub, with unsigned BuildKit attestations only. There is no signature to verify, so the evidence records "not applicable". The policy requires no attestations. See [Upstream trust classes](/architecture/upstream-trust-classes--01a18382f3fb.md).

## Enforcement

See `versions.json` for the current value. On 2026-10-28 the value was `observe`.

The image joined in `observe` mode. It stays in `observe` mode until a person records the day-one CVE triage in `.github/pdp/exceptions.yaml`. It is a JVM image of about 700 MB.

On 2026-10-28, the nexus3 leg had 88 blocking findings and 66 waived findings. It got a `PASS` verdict and went to `quarantine/`. See [On 2026-10-28 every build leg was trusted and every mirror leg was quarantined](/findings/on-2026-10-28-every-build-leg-was-trusted-and-every-mirror-leg-was-quarantined--01a1838a6fc5.md). See [ADR-001: Observe enforcement mode](/decisions/adr-001-observe-enforcement-mode--01a18382f44e.md) and [ADR-003: Quarantine is a documented state](/decisions/adr-003-quarantine-is-a-documented-state--01a18382f486.md).

## Variants and platforms

One variant, `runtime`, with a `-ubi` tag. Platforms: `linux/amd64`, `linux/arm64`.

The track is the 3.90 patch line of the `-ubi` tags. The upstream already has 3.91 tags. Thus a simple "newest tag" check would move up a minor version on its first run.

## Notes

* The upstream index holds BuildKit attestation manifests with the platform `unknown/unknown`. Their size changes between patch releases. The mirror leg removes them before the scan.
* The pipeline logs in to `docker.io` although the image is public. Anonymous Docker Hub pulls have a rate limit for each IP address, and GitHub runners share IP addresses.
* `SETUP-ENVIRONMENTS.md` uses nexus3 for the first GHCR referrers test and for the day-one CVE count.
