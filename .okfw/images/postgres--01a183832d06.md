# postgres

postgres is the PostgreSQL database. We mirror the Docker Hardened Images (DHI) build of it, for PostgreSQL 16 and 17.

## Track

Mirror track, from `dhi.io/postgres`. A rebuild would destroy the DHI signature and the DHI claim of zero known CVEs. See [Mirror track](/architecture/mirror-track--01a18382f29c.md).

## Trust class

`dhi`. The mirror leg verifies the DHI signature against `.github/pdp/keyring/dhi-latest.pub`. The policy requires a CycloneDX 1.6 SBOM and SLSA provenance v1. DHI images need an authenticated session to `dhi.io` and `registry.scout.docker.com`. See [Upstream trust classes](/architecture/upstream-trust-classes--01a18382f3fb.md).

## Enforcement

See `versions.json` for the current value. On 2026-10-28 the value was `enforce`.

## Variants and platforms

| Variant | Tag | Major |
|---|---|---|
| `runtime` | `16-debian` | 16 |
| `dev` | `16-debian-dev` | 16 |
| `runtime17` | `17-debian` | 17 |
| `dev17` | `17-debian-dev` | 17 |

Platforms: `linux/amd64`, `linux/arm64`.

Each track is an exact match of the tag. Only the digest moves. `drift-upstream.yml` proposes the new digest.

## Notes

* On 2026-09-15, we added PostgreSQL 17 as a second pair of variants, not as a second image. Both majors come from one `trusted/postgres` package, under their own upstream tags.
* The platform runs PostgreSQL 17 in two places: the GitLab database and chit-server. Before 2026-09-15, this image had only PostgreSQL 16. Thus neither consumer could stop its use of Docker Hub.
* A PostgreSQL 16 server cannot read a PostgreSQL 17 data directory. To move between majors, do a dump and a restore. Do not only change the image.

WARNING: `17-debian` uses Debian 13. The images that it replaces use Debian 12 (bookworm). A different glibc gives a different collation, so the order of text indexes can change. Run `REINDEX` on stored data after the move.
