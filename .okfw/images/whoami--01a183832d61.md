# whoami

whoami is the Traefik echo server. It is the test backend that the sm-ingress role of `infrashift/ansible-collection-infrashift-hashistack` runs behind the edge.

## Track

Mirror track, from `docker.io/traefik/whoami`. Before 2026-09-30, the consumer used the upstream `latest` tag. On 2026-09-30, we pinned the release that `latest` resolved to. See [Mirror track](/architecture/mirror-track--01a18382f29c.md).

## Trust class

`none`. The image has no cosign signature and no OCI referrers, only unsigned BuildKit attestation manifests in the index. See [Upstream trust classes](/architecture/upstream-trust-classes--01a18382f3fb.md).

## Enforcement

See `versions.json` for the current value. On 2026-10-28 the value was `observe`.

The image joined in `observe` mode. It stays in `observe` mode until a person records the day-one CVE triage in `.github/pdp/exceptions.yaml`. Expect Go `stdlib` findings from the toolchain that the vendor used.

On 2026-10-28, the whoami leg had 54 blocking findings, 18 for each of its three platforms. No waiver covered them. Thus the image went to `quarantine/` with a `PASS` verdict. Before that date, no issue tracked these findings. See [The whoami mirror has 54 blocking findings and no triage](/issues/the-whoami-mirror-has-54-blocking-findings-and-no-triage--01a1839ccc1d.md).

## Variants and platforms

One variant, `runtime`. Platforms: `linux/amd64`, `linux/arm`, `linux/arm64`.

* The upstream index holds `linux/arm/v7`. A mirror copies the whole index. Thus the declared set must include `linux/arm`, or `PLATFORM_SET_MISMATCH` denies.
* The track is the v1 release line. whoami is a stateless test fixture with no data or configuration contract. Thus a patch-only track would protect nothing from a minor bump.
* The track regex excludes the per-architecture tags and the two-part rolling tags.

## Notes

* The image is a scratch image with one static Go binary and no `USER`. It runs as root, which gives the warning `RUNTIME_RUNS_AS_ROOT`.
* The binary needs no privilege except a port below 1024. Run it as a non-root UID on a high port, for example `--user 65532:65532` and `--port=8080`. A test on 2026-09-30 showed that this works.
